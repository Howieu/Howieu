## Products

- [知选 Zhixuan](https://zhixuan.howieu.com) — 按预算导购：说出用途和预算，从真实在售的数码家电里挑一件，或按总价配一套。价格和"在预算内"只由程序判定。
- [ReportAgent](https://report.howieu.com) — 连接零售数仓的数据分析 Agent：对话查数、追问原因、经营体检和周度诊断报告。数字全部由程序计算，可查看 SQL。
